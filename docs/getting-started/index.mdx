## About NIMBORA

**NIMBORA is an open-source alternative to platforms like Vapi and Retell** - NIMBORA helps you build voice AI agents with an easy drag-and-drop workflow builder. Unlike proprietary solutions like Vapi, NIMBORA gives you:
- **100% open source** - no vendor lock-in, full transparency
- **Self-hostable** - deploy anywhere, own your infrastructure  
- **Complete control** - every line of code is open and customizable
- **2-minute setup** - from zero to working voice bot in under 2 minutes

## Setting up

Get the platform up and running using Docker with a small startup script on your local computer. If you are looking to deploy the platform on a server different than your local machine, please check the [Deployment](deployment/introduction) section.

<Note>We collect anonymous usage data to improve the product. You can opt out by setting `ENABLE_TELEMETRY=false` before running the startup script.</Note>

<CodeGroup>
```bash macOS/Linux
curl -o docker-compose.yaml https://raw.githubusercontent.com/optimiumnexusllc/nimbora/main/docker-compose.yaml && curl -o start_docker.sh https://raw.githubusercontent.com/optimiumnexusllc/nimbora/main/scripts/start_docker.sh && chmod +x start_docker.sh && ./start_docker.sh
```
```powershell Windows
Invoke-WebRequest -OutFile docker-compose.yaml https://raw.githubusercontent.com/optimiumnexusllc/nimbora/main/docker-compose.yaml; Invoke-WebRequest -OutFile start_docker.ps1 https://raw.githubusercontent.com/optimiumnexusllc/nimbora/main/scripts/start_docker.ps1; .\start_docker.ps1
```
</CodeGroup>

Please check [Prerequisites](getting-started/prerequisites) for the system requirements and [Troubleshooting](getting-started/troubleshooting) for common issues.
